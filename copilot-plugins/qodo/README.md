# Qodo for GitHub Copilot

Qodo setup, code intelligence, and review workflows.

Install Qodo CLI 2.0.0 or newer and invoke the qodo-setup skill.
Copilot manages this plugin. Install Qodo Standards separately if you need it.

Installation and support: https://github.com/qodo-ai/qodo-skills/blob/main/docs/copilot.md
